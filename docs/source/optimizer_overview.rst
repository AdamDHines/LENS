Overview
==================
In order to get the best accuracy from networks on custom datasets, the hyperparameters of LENS should be tuned and tailored to each dataset.

LENS provides a simple, easy to use optimizer script using `Weights & Biases <https://wandb.ai/site/>`_ to run either grid or random sweeps 
of hyperparameters to maximize localization accuracy.

.. note::
    
    For more information, please visit the `Weights & Biases documentation <https://docs.wandb.ai/guides/>`_.
